# - トピック直接アクセス機能

## 概要

CHiBi-CHiLO の外部ツールでは、教材内の特定トピックを指定して配信できます．\
受講者が Moodle上のリンクを開くと、指定したトピックから再生が開始されます．

## 開始トピックの設定

{% hint style="info" %}
ブック内のサムネイルをクリックすると、開始トピックを選択できます．\
トピックを選択すると、選択画面は自動的に閉じます．
{% endhint %}

### 設定方法

1. CHiBi-CHiLOを追加します
2. 「コンテンツを選択する」ボタンをクリックします
3. ブックを選択します
4. 開始したいトピックのリンクアイコンを選択します
5. トピック選択後、画面は自動的に閉じます
6. 設定を保存します

「動画」

### 受講者の表示

* 指定したトピックから再生されます
* 指定したトピックの再生終了後は次のトピックへ自動遷移します
* 目次から他のトピックへ移動できます

## 開始トピックの変更

開始トピックを変更する際はCHiBi-CHiLOの設定を編集からコンテンツを再度選択し直して保存します．

「設定を編集の画像」

***

## 注意事項

* トピック未指定時は、ブック先頭から表示されます
* 削除済みトピックを指定している場合はエラーが表示されます
* トピック変更後は、必ず設定を保存してください
