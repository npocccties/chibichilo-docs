# - トピック直接アクセス機能

### 概要

CHiBi-CHiLO の外部ツールでは、教材内の特定トピックを指定して配信できます。\
受講者が Moodle上のリンクを開くと、指定したトピックから再生が開始されます。

### 開始トピックの設定

{% hint style="info" %}
ブック内のサムネイルをクリックすると、開始トピックを選択できます。\
トピックを選択すると、選択画面は自動的に閉じます。
{% endhint %}

1. 「Select content」からブックを選択します
2. ブック内のサムネイルをクリックします
3. 開始したいトピックを選択します
4. トピック選択後、画面は自動的に閉じます
5. Moodle 側で保存します

### 受講者の表示

* 指定したトピックから再生されます
* トピック終了後は次のトピックへ自動遷移します
* 目次から他のトピックへ移動できます

### 開始トピックの変更

1. 「Select content」を再度実行します
2. 新しいトピックを選択します
3. Moodle 側で保存します

***

### 注意事項

* トピック未指定時は、ブック先頭から表示されます
* 削除済みトピックを指定している場合はエラーが表示されます
* トピック変更後は、必ず Moodle 側で保存してください
