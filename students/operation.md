# - 学習者の操作方法

## プレイヤーの操作

![](../.gitbook/assets/operation_01.png)

| 項目         | 内容                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------- |
| ❶戻る/進む   | 15秒ずつ移動出来ます                                        |
| ❷音量   | 音量を調整出来ます．                                                                           |
| ❸シークバー        | 再生位置を調整出来ます． |
| ❹再生速度      | 再生速度を調整出来ます．0.25〜2倍まで選択可能です。   |
| ❺字幕 | 字幕を表示出来ます．                                                    |

## 解説

## 完了ラベル

トピック内の動画を最後まで視聴すると，目次のトピック名の右に， **「完了」** のアイコンが表示されます．

![](../.gitbook/assets/dashboard_01.png)

## タグ

プレイヤー下部の **「タグを追加」** からトピックごとにタグを設定出来ます．追加した場所とトピックリストに追加したタグが表示されます．

![](../.gitbook/assets/operation_02.png)
